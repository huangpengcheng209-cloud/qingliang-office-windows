# 社区版下一步

本路线针对公开的 win.22 修改版，另一条独立实现路线不在此仓库内。

| 顺序 | 交付 | 验收条件 |
| --- | --- | --- |
| 1 | 自动源码检查 | Windows/Linux 检查 96 个修改文件、累计补丁、固定上游字节与保护行为；不执行应用构建 |
| 2 | 可移植构建入口 | 消除对原机器路径和未公开基线的依赖，在一台新 Windows 环境记录完整依赖与组件构建流程 |
| 3 | 依赖材料 | 补齐 VLC x64 下游补丁、静态依赖版本/配置，按实际组件核对对应源码及许可 |
| 4 | 可安装 Beta | 材料满足分发要求后，构建一个固定安装包，完成安装、编辑、保存、转换、卸载及文档保留验收 |
| 5 | 兼容性改进 | 用脱敏真实文件追踪复杂表格、脚注分页及 PPTX 历史异常，逐项记录可复现问题 |

源码自动检查通过不能替代完整编译、应用运行或分发材料核查。保持现有功能和源码，不通过删除插件来掩盖依赖缺项。
