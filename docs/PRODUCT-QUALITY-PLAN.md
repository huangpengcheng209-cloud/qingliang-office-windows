# 氢量办公：功能与质感完善清单

目标：全面完善软件功能和高级感。范围包含已有文档、表格、演示、PDF/表单能力，以及完整桌面交互、视觉和动效；不以首页美化或单个组件通过作为完成标准。保留已有功能、插件及法律声明。

## 当前可核实的进展

- 固定源码、原生保存、依赖及完整 x2t 的前序证据见各构建说明。转换器组件验收不能替代编辑器验收。
- 第一批工作台改进已实现并构建真实起始页；37 项浏览器检查本机通过，包括搜索、筛选、键盘命令、异步历史列表、明暗主题和减少动效。详见 [WORKBENCH-QUALITY.md](WORKBENCH-QUALITY.md)。
- 新桌面宿主、Qt 包装与可安装应用尚未构建。首页测试使用明确隔离的原生边界测试适配器，未据此声称实际文件编辑、保存或系统对话框成功。
