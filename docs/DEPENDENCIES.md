# 依赖来源

主源码的九个固定上游仓库见 ../upstream.lock.json，原始许可见 ../licenses/upstream/。修改文件和补丁取自固定 win.22 程序源码快照。

原运行时还包含 Qt 5.15.2、CEF 150.0.22 / Chromium 150.0.7871.256、VLC 3.0.21 系列、Boost 1.72.0、ICU 74.2、OCR、字体和字典。它们未随本源码仓库重新分发为运行时二进制。OCR 来源记录和相关许可见 ../licenses/ocr/，其他依赖的获取/构建参考位于 ../historical-build/。

VLC 275 个模块/主库有源码目标映射，但这不证明历史静态依赖和下游补丁完整对应；该缺口仍保留。今后如提供安装包，应根据实际运行组件重新建立许可和对应源码清单。
